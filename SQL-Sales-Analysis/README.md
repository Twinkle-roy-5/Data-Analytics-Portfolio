# SQL Sales & Customer Analysis

## Project Overview

A SQL-based analysis project using customer, order, product, and employee data to perform sales analysis, customer analysis, and employee salary analysis.

## Key Analysis

* Customer-wise total revenue
* Product-wise sales quantity and revenue
* Orders by city
* Order delivery status classification
* Customer and order analysis using JOINs
* Employee salary ranking
* Customer-level ranking using Window Functions

## SQL Concepts Used

* SELECT
* INNER JOIN
* LEFT JOIN
* GROUP BY
* ORDER BY
* Aggregate Functions
* CASE WHEN
* CTE (Common Table Expression)
* ROW_NUMBER()
* PARTITION BY
* DENSE_RANK()
* Window Functions

## Tools Used

* PostgreSQL
* SQL
* Data Analysis

## Project Files

* `sales_analysis.sql` – SQL queries used for analysis
