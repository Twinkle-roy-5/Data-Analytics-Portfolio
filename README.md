# Sales Incentive Performance Dashboard

## Project Overview

An interactive Excel dashboard developed to analyze salesperson performance, incentive payouts, achievement levels, and monthly incentive trends.

## Objectives

- Analyze salesperson incentive performance
- Identify top-performing salespersons
- Track achievement levels against targets
- Analyze monthly incentive trends
- Provide an interactive management dashboard

## Tools & Skills

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Analysis
- Dashboard Design
- KPI Analysis

## Dashboard Features

- Total Incentive Paid
- Top Performer
- Average Achievement
- Highest Achievement
- Total Salespersons
- Top 10 Salespersons by Incentive
- Monthly Incentive & Achievement Trend
- Interactive Year-Month and Remarks filters

## Key Insights

- Identified the salesperson with the highest total incentive.
- Analyzed achievement performance across different months.
- Compared incentive payouts across salespersons.
- Used interactive filters to analyze performance.
